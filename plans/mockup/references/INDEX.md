# Reference set — professional creative tools, neutral dark

19 curated screenshots of software with the look we are targeting. Each row gives the
local copy, the product page, and the direct screenshot URL it came from.

How to read this set: the target is **canvas-dominant, neutral dark chrome, one accent
color, calm type scale**. The sprite art is the only saturated thing on screen.

## How this set was collected

`tools/gather_refs.py` queries Bing Images with the
product name **quoted** and `filterui:imagesize-large`. Two traps found the hard way:

- `qft=+filterui:photo-photo` **excludes** screenshots and matches literal words —
  "spline" returned metal shafts, "linear" returned graphs, "cavalry" returned horses.
- Unquoted product names behave the same way. Quote them.

Precision was ~40%, so the gaps were filled by harvesting `<img>` tags from each
product's own documentation page (`harvest_docs.py`), which is far more reliable.
Marketing homepages are not usable: they show hero artwork and cookie walls, not UI.
